Binary Tree DFS
Sep 6, 2024

Overview

In computer science, tree traversal is a form of graph travrsal and refers to the process of visiting each node in a tree data structure, exactly once. Such traversals are classified by the order in which the nodes are visited.

DFS

In depth-first search(DFS), the search tree is deepened as much as possible before going to the next sibling. To traverse binary trees with depth-first search, perform the following operations at each node:

  1. If the current node is empty then return
  2. Execute the following tree operations in a certain order
    N: Visit the current node.
    L: Recursively traverse the current node’s left subtree
    R: Recursively traverse the current node’s right subtree.

Pre-order, NLR
Post-order, LRN
In-order, LNR
Reverse pre-order, NRL
Reverse post-order, RLN
Reverse in-order, RNL

Given a tree with distinct elements, either pre-order or post-order paired with in-order is sufficient to describe the tree uniquely. However, pre-order with post-order leaves some ambiguity in the tree structure.

Problems

Construct Binary Tree from Preorder and Inorder Traversal

class Solution {
public:
    int pidx;
    unordered_map<int,int> mp;
    TreeNode* buildTree(vector<int>& preorder, vector<int>& inorder) {
        pidx=0;
        int len=inorder.size();
        for(int i=0;i<len;i++){
            mp[inorder[i]]=i;
        }
        return construct(0,len-1,preorder);
    }
    TreeNode* construct(int start,int end,vector<int>&preorder){
        if(start>end) return NULL;
        int rootval=preorder[pidx];
        TreeNode *head= new TreeNode(rootval);
        int mid=mp[rootval];
        pidx++;
        head->left=construct(start,mid-1,preorder);
        head->right=construct(mid+1,end,preorder);
        return head;
    }
};

Construct Binary Tree from inorder and postorder traversal

class Solution {
public:
    int pidx;
    unordered_map<int,int> mp;
    TreeNode* buildTree(vector<int>& inorder, vector<int>& postorder) {
        int len=inorder.size();
        pidx=len-1;
        for(int i=0;i<len;i++){
            mp[inorder[i]]=i;
        }
        return construct(0,len-1,postorder);
    }
    TreeNode* construct(int start,int end,vector<int>&postorder){
        if(start>end) return NULL;
        int rootval=postorder[pidx];
        TreeNode* head= new TreeNode(rootval);
        int mid=mp[rootval];
        pidx--;
        head->right=construct(mid+1,end,postorder);
        head->left=construct(start,mid-1,postorder);
        return head;
    }
};

Everytime we create a new node with a number from preorder array. That should be root node of each subtree, because in preorder, we traverse the tree like root, left and right. So let’s say middle(=root)
To create left and right side of tree, we use two pointers, let’s say start and end.
Start and end specify the range of the current subtree in the inorder list.
Within this range, the root node is determined, and itd index is used to recursively set the ranges for the left and right subtrees.

Binary Tree Maximum Path Sum

class Solution {
public:
    int max_sum=INT_MIN;
    int maxPathSum(TreeNode* root) {
        max_gain(root);
        return max_sum;
    }
    int max_gain(TreeNode* root){
        if(!root) return 0;
        int l=max(max_gain(root->left),0);
        int r=max(max_gain(root->right),0);
        int new_price=root->val+l+r;
        max_sum=max(max_sum,new_price);
        return root->val+max(l,r);
    }
};

In this problem we use postorder traversal to calculate the maximum path sum of subtrees. For each node we can choose either its left subtree or right subtree, so our return value is root->val+max(l,r) However, each node may be an end point, so the correct answer of maximum sum is int new_price=root->val+l+r; max_sum=max(max_sum,new_price);

Flatten Binary Tree to Linked List

class Solution {
public:
    void flatten(TreeNode* root) {
        if(root) preorder(root); 
    }
    TreeNode* preorder(TreeNode* root){
        TreeNode* leftmost=root;
        if(root){
            TreeNode* left=root->left;
            TreeNode* right=root->right;
            root->right=left;
            root->left=NULL;
            if(left) leftmost=preorder(left); //deal with its left subtree
            if(right){
               leftmost->right=right;
               leftmost=preorder(right); //deal with its right subtree
            }
        }
        return leftmost;
    }
};

If we notice carefully in the flattened tree, each node’s right child points to the next node of a pre-order traversal, so we return the leftmost node untile all left node was added to the list and we started to deal with right node( though the variable name still called leftmost )

Common Data Structure in DFS

I prefer use recursive function to implement DFS, however stack is also an useful data structure to implement DFS. There is a problem ask programers useing stack to implement Binary Search Tree Inorder Iterator.
Binary Search Tree Iterator

//Inorder
class BSTIterator {
public:
    stack<TreeNode*>s;
    BSTIterator(TreeNode* root) {
        Inorder(root);
    }
    
    int next() {
        TreeNode* top=s.top();
        s.pop();
        Inorder(top->right);
        return top->val;
    }
    
    bool hasNext() {
        return !s.empty();
    }
    void Inorder(TreeNode* root){
        while(root){
            s.push(root);
            root=root->left;
        }
    }
};

Notice that we should put a node’s left child on the top of the stack to ensure the ordering is in-order. If we want to change it to pre-order or post-order we can modify our code to this

//Preorder
class BSTIterator {
public:
    stack<TreeNode*>s;
    TreeNode *now;
    BSTIterator(TreeNode* root) {
        s.push(root);
    }
    
    int next() {
        TreeNode *now=s.top();
        Preorder(now);
        s.pop();
        return now->val;
    }
    
    bool hasNext() {
        return !s.empty();
    }
    void Preorder(TreeNode* root){
        if(root->right) s.push(root->right);
        if(root->left) s.push(root->left);
    }
};

//Postorder
class BSTIterator {
public:
    stack<TreeNode*>s;
    BSTIterator(TreeNode* root) {
        Postorder(root);
    }
    
    int next() {
        TreeNode *top=s.top();
        s.pop();
        Postorder(top->left);
        return top>val;
    }
    
    bool hasNext() {
        return !s.empty();
    }
    void Postorder(TreeNode* root){
        while(root){
            s.push(root);
            if(root->right) s.push(root->right);
            root=root->left;
        }
    }
};

Conclusion

The time and space analysis of DFS differs according to its application area.In theoretical computer science, DFS is typically used to traverse an entire graph(tree), and takes time $O(|V|+|E|)$. This is linear in the size of the graph. In these applications it also uses space $O(|V|)$ in the worst case to store the stack of vertices on the current search path as well as the set of already-visited vertices. Thus, in this setting, the time and bounds are the same as fpr breadth-first search and the choice of which of these two algorithms to use depends less on their complexity and more on the different properties of the vertex orderings the two algorithms produce.
